# Dịch Tài Liệu PDF

Dịch tài liệu PDF sang hơn 60 thứ tiếng ngay trên trình duyệt. Miễn phí, không đăng nhập, không quảng cáo.

**Dùng ngay:** https://h04ng1.github.io/dich-tai-lieu-pdf/

- Kéo thả file PDF, chọn ngôn ngữ, bấm Dịch.
- Xem song ngữ hoặc chỉ bản dịch, sửa tay từng đoạn, tìm kiếm.
- Bảng tên riêng & thuật ngữ để tên người, tên công ty không bị dịch lung tung.
- Tự lưu tiến độ trên máy: tải lại trang vẫn dịch tiếp được.
- Xuất TXT, HTML song ngữ, EPUB, hoặc In / Lưu PDF.

Tài liệu chỉ nằm trên máy bạn. Chỉ phần chữ cần dịch được gửi tới Google Translate (bản miễn phí, tài liệu dài có thể chậm).
PDF dạng ảnh scan chưa được hỗ trợ.

Toàn bộ trang nằm trong một file `index.html`, có thể tải về và mở thẳng bằng trình duyệt.
